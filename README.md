# React Tac Toe 🎮

> Because someone had to do it, and apparently that someone was me.

A tic-tac-toe game built with React. Yes, another one. But this one's *mine*.

## What Is This?

It's tic-tac-toe. You know, that game you played on paper in elementary school when you were supposed to be doing actual work? Now you can play it in your browser while you're supposed to be doing actual work.

## Features

- ✨ Click on squares to place X's and O's
- 🔄 Automatically switches between players (revolutionary, I know)
- 🎨 Has CSS styles and everything
- ⚛️ Built with React because using vanilla JS would be too simple
- 🚀 Powered by Vite for that blazingly fast dev experience you don't really need for tic-tac-toe

## Getting Started

### Prerequisites

- Node.js (probably any recent version will work, it's just tic-tac-toe)
- npm or your package manager of choice

### Installation

1. Clone this repository
```bash
git clone <your-repo-url>
cd tic_tac_toe
```

2. Install dependencies
```bash
npm install
```

3. Start the development server
```bash
npm run dev
```

4. Open your browser to `http://localhost:5173` (or whatever port Vite decides to use)

## Available Scripts

- `npm run dev` - Start the development server
- `npm run build` - Build for production (because your tic-tac-toe game needs to be production-ready)
- `npm run lint` - Check your code style
- `npm run preview` - Preview the production build

## How to Play

1. Click a square
2. The other player clicks a square
3. Repeat until someone wins or you realize you could've just used paper

## Tech Stack
